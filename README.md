Personal Expense Tracker
A Python-based personal expense management application built by Obedience Jay as part of my software development learning journey.
The project demonstrates practical Python skills through expense tracking, input validation, defensive file handling, backup and recovery, spending analytics, and professional report generation.
🚀 Features
Add and save personal expenses
Validate expense names, amounts, categories, and dates
Load previously saved expense records
Handle malformed records safely
Create a backup before updating expense data
Calculate total spending
Calculate average expense
Count recorded expenses
Analyze spending by category
Identify the highest-spending category
Find the largest and smallest expense
Analyze daily spending
Calculate category percentages
Calculate daily spending percentages
Analyze spending by weekday
Display complete expense history
Export a professional expense report

🔐 Data Safety
Personal expense data is intentionally excluded from the public repository.
The .gitignore file prevents personal expense records, Python cache files, and development backup files from being tracked by Git.
This keeps the public repository focused on the application, documentation, and portfolio demonstration.
