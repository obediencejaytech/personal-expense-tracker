Personal Expense Tracker
A Python-based personal expense tracking application built by Obedience Jay.
This project was developed as part of my Python and software development learning journey. It demonstrates practical programming skills including input validation, file handling, defensive data processing, data analysis, backup and recovery, and report generation.
🚀 Features
Add and save personal expenses
Validate expense names, amounts, categories, and dates
Load previously saved expense records
Handle invalid or malformed records safely
Automatically create a backup before updating expense data
Calculate total spending
Calculate average expense
Count recorded expenses
Analyze spending by category
Identify the highest-spending category
Find the largest and smallest expense
Analyze daily spending
Calculate category spending percentages
Calculate daily spending percentages
Analyze spending by weekday
Display complete expense history
Export a professional text report

🔐 Data Safety
Personal expense data is intentionally excluded from the public GitHub repository.
The .gitignore file prevents personal data, Python cache files, and development backup files from being tracked.
This keeps the public repository focused on the application code and project documentation.
